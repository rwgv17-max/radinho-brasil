# Radinho Brasil

Rádios FM e AM de todo o Brasil, ao vivo, num radinho à pilha.

Escolha o estado no mapa, clique numa cidade e sintonize. Dá para salvar até seis favoritas nas memórias do rádio.

**Projeto idealizado por Roger Vargas.**

## Instalar no celular

- **Android (Chrome):** abra o link do app, toque nos três pontinhos e escolha **Instalar app**.
- **iPhone (Safari):** abra o link, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

## De onde vêm os dados

- Mapas: [IBGE](https://servicodados.ibge.gov.br/api/docs/malhas)
- Emissoras: [Radio Browser](https://www.radio-browser.info), base colaborativa
- Emissoras cadastradas à mão (ex.: Alegrete): lista `EXTRA` dentro do `index.html`
